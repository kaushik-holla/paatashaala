# Changelog

## 0.1.0 — 2026-09-26

First standalone Paatashaala source release. The application has an English-first learning experience for the US and India, including the course creation flow, interactive classroom, sample lesson, and Paatashaala visual theme. Learners can use ChatGPT browser sign-in or configure supported AI providers with an API key and choose their default model in Settings.

This changelog records Paatashaala releases from its first independent source release. See the [credits and license](README.md#credits-and-license) for the original foundation and notices.
